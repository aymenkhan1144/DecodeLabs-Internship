# Project 1 — Responsive Frontend Interface

A responsive, mobile-first frontend built with vanilla HTML, CSS, and JavaScript — no frameworks. Built for the DecodeLabs Full Stack Development Internship (2026 batch).

## Features

- **Semantic HTML5** — proper use of `<header>`, `<nav>`, `<main>`, `<article>`, `<footer>` for accessibility and SEO
- **Mobile-first responsive design** — single column on mobile, expanding to 2 columns at 768px (tablet) and 4 columns at 1024px (desktop)
- **CSS Grid** for page-level layout, **Flexbox** for component-level layout (nav bar, service cards)
- **Fluid typography** using `clamp()` — text scales smoothly across screen sizes without breakpoints
- **2025-inspired color palette** — Mocha Mousse, Ethereal Blue, Moonlit Grey
- **JavaScript interactivity** — animated hamburger menu toggle, dynamic "Load More" content loader

## Tech Stack

HTML5, CSS3 (Grid, Flexbox, `clamp()`), Vanilla JavaScript

## How to Run

Just open `index.html` in any browser — no build step, no dependencies.

## Files

- `index.html` — page structure
- `style.css` — all styling, responsive breakpoints, color palette
- `script.js` — nav toggle and content loader logic
